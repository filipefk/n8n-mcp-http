🔑 Gerador de API Key — n8n MCP

O servidor MCP recebe um único header, x-api-key, que junta numa só string a sua chave de acesso ao MCP e, opcionalmente, a URL e a API Key da sua instância do n8n. Esta página monta essa string para você — e também faz o caminho inverso.

1. Identifique-seInforme a chave MCP que o administrador do servidor liberou para você.
2. Gere a keyPreencha a URL e a API Key do n8n (ou deixe em branco para usar as do servidor).
3. Use no clienteCopie a key e cadastre-a no header x-api-key do Claude Code, Copilot Studio etc.

1 Sua chave MCP

Necessária para usar esta página: o servidor só gera ou decodifica keys para quem tem uma chave válida.

É uma das chaves cadastradas em McpAuth:ApiKeys no servidor. Não sabe qual é? Peça a quem administra o servidor.

2 O que você quer fazer?

Gere uma key nova, ou cole uma key existente para conferir o que há dentro dela.

É o caso comum. Desmarque só se a key for para outra pessoa, com outra chave MCP.

Só o endereço base da instância, sem /api/v1 e sem barra no fim — o servidor completa o caminho da API.

Como obter a URL e a API Key do n8n
  1. Faça login no n8n e copie da barra de endereços o começo da URL, até o domínio. Exemplo: de https://n8n.minha-empresa.com/home/workflows fica https://n8n.minha-empresa.com. Cole no campo URL da instância n8n.
  2. No menu Settings, no canto inferior esquerdo, escolha a opção n8n API.
  3. Clique em Create an API Key.
  4. Dê um nome, escolha a expiração e selecione as permissões que esta API Key terá (podem ser editadas depois). Clique em Save.
  5. Copie o valor gerado e cole no campo API Key do n8n. O n8n só mostra a chave uma vez; se você a perder, será preciso gerar outra.

💡 Deixando URL e API Key do n8n em branco, o servidor usa a instância e a credencial da configuração dele.

✅ Key gerada

⚠️ Trate a key como uma senha: ela não é criptografada, só embaralhada — quem a tiver consegue recuperar a API Key do n8n que está dentro dela. Cada clique em "Gerar" produz uma key diferente, e todas são válidas.
